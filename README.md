# Coding Assessment

This repository contains the solutions for the assigned coding problems.

Each problem is maintained independently in its own folder with its implementation and supporting documentation.

## Repository Structure

```text
EverQuint/
│
├── README.md
│
├── WaterTank/
│   ├── README.md
│   ├── Approach.md
│   ├── Decision.md
│   └── source files
│
└── MaxProfit/
    ├── README.md
    ├── Approach.md
    ├── Decision.md
    └── source files
```

## Documentation

Each problem folder contains:

* **README.md** — How to run the solution, project structure, and implementation overview.
* **Approach.md** — Problem-solving approach and algorithm explanation.
* **Decision.md** — Key assumptions, design decisions, alternatives considered, and trade-offs.

The problem-specific README files should be referred to for setup and execution instructions.
